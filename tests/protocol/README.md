# Protocol tests

**Reserved — populated from Stage 1B.**

Conformance tests for EMV 3DS message handling: schema validation per message type and version,
conditional field presence, Erro generation, and end-to-end AReq/ARes, CReq/CRes and RReq/RRes flows
driven by the simulator. Each test references the specification section it covers and, where relevant,
a compliance matrix ID (`EMV-xx`). Test messages are synthetic.

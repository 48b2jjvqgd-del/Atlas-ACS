# Compliance tests

**Reserved — populated from Stage 4.**

Executable checks for requirements in the [compliance matrix](../../docs/compliance/COMPLIANCE_MATRIX.md),
e.g. SCA exemption evaluation and scheme rule enforcement. Every test names the matrix ID it evidences,
so the matrix's progress column can be backed by test results. Requirements still marked _Research_ or
_Assumption_ are not encoded as tests until confirmed.
